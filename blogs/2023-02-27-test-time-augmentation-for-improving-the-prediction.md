Test-Time Data Augmentation (short TTA) is a strategy that can raise a deep learning model’s performance by applying augmentation during inference. Inference is performed on multiple altered versions of the same image, and the predictions are then aggregated to get a higher overall accuracy. Unlike train-time data augmentation , we don’t need to make any changes to the model, therefore it can be applied to an already trained model!
